# Trạm Gác

Game bắn súng 3D góc nhìn thứ nhất chạy ngay trên trình duyệt điện thoại, viết bằng three.js. Bạn giữ trạm trong một khu vực rộng có nhà và thùng, hạ từng đợt bot hình người đang bắn trả.

Mở `index.html` bằng trình duyệt là chơi được (cần mạng để tải three.js và font).

## Điều khiển trên điện thoại

- **Cần trái:** di chuyển.
- **Kéo ngón tay trên màn hình** hoặc kéo ngay trên nút **BẮN**: xoay ngắm.
- **BẮN:** bắn. Tâm ngắm lại gần bot thì tự bắn và đạn tự bám mục tiêu.
- **NGẮM:** phóng to, đạn chụm hơn, đi chậm lại.
- **BL / SMG / SG / SN / GL:** đổi súng (súng trường, tiểu liên, hoa cải, bắn tỉa, phóng lựu).
- **BOM:** gọi máy bay ném bom vào chỗ tâm ngắm, hồi 40 giây.
- **NUKE:** siêu bom từ trên trời, vòng cảnh báo rất to, hồi 75 giây.

## Điều khiển trên máy tính

- Bấm **Bắt đầu** để khóa chuột, `Esc` để nghỉ.
- `W A S D`: di chuyển, **chuột**: xoay ngắm
- **Chuột trái**: bắn, **giữ chuột phải**: ngắm xa
- **Lăn chuột** hoặc `1` đến `5`: đổi súng
- `E`: BOM, `R`: NUKE
- Nếu trình duyệt không cho khóa chuột: kéo chuột để xoay, `Space` để bắn, mũi tên trái/phải để xoay

## Chơi trên web bằng GitHub Pages

Vào Settings, chọn Pages, đặt nguồn là nhánh `main` thư mục gốc. Sau vài phút game chạy được ở địa chỉ GitHub Pages của repo.
